# Pengenalan

**Zhuxe Asistance** (`zhuxe-assistance`) adalah library TypeScript untuk berinteraksi dengan protokol WhatsApp Web. Versi 1.0 dinyatakan stabil dan mengikuti SemVer.

Proyek ini adalah fork dari [zapo-js](https://github.com/vinikjkkj/zapo-js) karya vinikjkkj, berlisensi MIT.

## Fitur

- Pesan teks dan media (gambar, video, audio, dokumen, stiker, voice note)
- Grup, termasuk enkripsi SenderKey
- Newsletter
- Panggilan suara lewat plugin VoIP
- Banyak akun dalam satu proses (`sessionId` berbeda)
- Sistem plugin
- Store persisten: SQLite, PostgreSQL, MySQL, MongoDB, Redis
- Akselerator kripto native opsional

## Kebutuhan

| Kebutuhan | Keterangan |
|-----------|-----------|
| Node.js | 20.9.0 atau lebih baru |
| Dependensi runtime paket inti | Tidak ada yang wajib |
| ffmpeg dan ffprobe | Hanya untuk fitur media tertentu (opsional) |
