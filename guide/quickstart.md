# Mulai Cepat

Bot pertama ini mendengarkan pesan masuk. Kalau ada yang mengirim teks **"Halo"**, bot membalas **"Halo juga! Saya Zhuxe Bot."**

## Langkah 1: Buat file

Buat file `index.js` di folder project.

::: warning TODO

## Langkah 2: Jalankan

```bash
node index.js
```

Scan QR yang muncul di terminal. Dengan [store](/concepts/stores), login tersimpan dan tidak perlu scan lagi saat bot dinyalakan ulang.
