# Fitur Lanjutan: Panggilan (VoIP)

Zhuxe mendukung fitur panggilan suara dan video melalui package tambahan @zhuxe-js/voip.

## Instalasi
npm install @zhuxe-js/voip @zhuxe-js/voip-media

## Fitur yang Didukung:
- Panggilan Suara (Audio Call)
- Panggilan Video (Video Call)
- Kodek MLow (khusus WhatsApp)
- WebRTC / STUN / Relay
